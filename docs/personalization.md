# Public rules, private configuration

This distribution publishes reusable workflow choices. It does not publish a
user profile or replicate a personal workstation.

Keep complete account/project instructions, machine-specific bindings, tool
permissions, local paths, service accounts and runtime records in the host's
private configuration. The repository does not create those bindings or infer
permission from an example. Apply the optional instruction fragment only to the
matching SP clauses and preserve unrelated or concurrent edits.

The initial snapshot was selected from skills, required public assets, Codex
manifests, the upstream license and targeted test source. Private installation
reports, raw evaluation results, backups, account AGENTS files and original Git
metadata were excluded. A task-scoped content check was performed before
publication; it is not a permanent secret scanner or a universal privacy proof.

Commit identity uses the account's GitHub noreply address. GPG signatures use an
existing account-associated signing key; no private key or public-key export is
bundled in this repository. A signature attests to the commit identity and
integrity, not to correctness, trustworthiness or runtime authorization.
