# Optional account/project instruction fragment

Merge only the SP-related fragment at the appropriate host instruction level.
Do not replace an entire account or project instruction file with this example.

```text
Superpowers is enabled only when the current user explicitly enables it for
this task or names a specific skill. Ordinary requests, quoted examples,
history, and editing skill text do not activate it. One named skill does not
authorize the complete chain. Necessary ordinary engineering work continues.

Resume the current authorized scope; do not revive canceled or transferred
tasks. Completion, cancellation or an explicit close ends the workflow.

Reuse evidence for unchanged relevant state and the same acceptance claim.
Known defects, unmet explicit requirements and mandatory host checks still
require appropriate verification. Do not repeat checks only to change phase
or prepare a report. Keep personal configuration and private artifacts local.
```

This fragment is a model instruction. It does not grant access, change sandbox
settings, authorize external transmission, or replace required approvals.
