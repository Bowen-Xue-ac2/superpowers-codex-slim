# Superpowers Codex Slim — contribution scope

Work only on the requested change. Editing or reviewing skill text does not
activate that skill or the complete Superpowers workflow. Explicit requests for
one skill do not authorize other named workflows or delegation.

Preserve valid evidence for unchanged relevant state. Recheck concrete gaps and
affected behavior; known defects and mandatory requirements remain blockers.
Do not create evidence, new verification layers or extra scope merely to finish.

Keep account configuration, local paths, credentials, private keys, business data,
raw sessions, receipts and backups outside this public repository. Public
examples must use generic paths and fixtures. Never publish a local Git history
or account AGENTS.md as a shortcut to packaging. Preserve upstream attribution.
